# Decoraciones Coco's

Bilingual website for Decoraciones Coco's — event decor, party rentals, galleries, and custom event quote requests.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Project priorities

- Mobile-first experience
- English + Spanish content
- Fast, optimized images (WebP/AVIF)
- Lightweight repository and asset strategy
- Simple event quote flow
- Real Decoraciones Coco's photography rather than stock imagery

## Status

Initial homepage foundation is in place. Service imagery, gallery photography, final business details, and the quote workflow will be added next.
